年払いZOOM会議まとめ

かんたん版｜番号をタップすると詳しく読めます

3行で全体像

  • 再生数とフォローは、どちらか一方を諦めなくていい。
  • 動画は「最初に止める → 中身で信頼 → 最後にフォローしたくなる」流れで作る。
  • 伸びた型は使い回し、他のSNSにも同じ動画を載せてOK。

1再生数とフォロー、両方狙える

一言で言うと

「再生を取るならフォローは諦める」は間違い。1本の動画の中で、見てもらう → 好きになる → フォローするまで設計しよう。

1本の動画の流れ（4ステップ）

  1. 最初の2秒
    指を止める。誰向けかははっきりしすぎず、多くの人が「おっ？」と思う映像＋言葉でOK。
  2. 真ん中
    「ためになる」「共感できる」内容を入れる。
  3. 後半
    「フォローしてね」だけだとスルーされやすい。「この人の他の投稿も見たい」と思わせる理由を入れる。
  4. プロフィール
    プロフィールを見た人が迷わずフォローできるように整える。

数字の見方（3つセットで見る）

次の3つをセットでチェックすると、どこを直せばいいか分かります。

  • 再生数 … どれだけ見られたか
  • プロフィール遷移率 … プロフィールを見に行った人の割合
  • フォロー率 … フォローしてくれた人の割合

例：再生は多いのにフォローが少ない → 後半やプロフィールを見直す、など。

2トライアルリール（お試し投稿）の使い方

一言で言うと

「お試し用の投稿機能」。理由なく使いすぎない。普段の投稿が基本。

やらない方がいい

なんとなく毎回使う

アカウントのイメージがブレやすい。最初は普通の投稿を続けること。

こんな時だけ使う

  • 冒頭の言い方を2パターン試したい
  • 新しい編集スタイルを試したい
  • 伸びた動画を、少し変えてもう一度出したい
  • 別の層（年齢・属性）に刺さるか試したい

3同じ動画をTikTok・YouTubeにも載せる

一言で言うと

インスタ用に作った動画を、そのままTikTokとYouTube Shortsにも載せてOK。最初からやって大丈夫。

うれしいこと

  • 作り直し不要で、手間がほとんど増えない
  • インスタ以外でもフォロワーを増やせる
  • あとからお金を稼ぐ方法（TikTok Shopなど）の選択肢が増える

4心構え・続けるコツ

一言で言うと

1本の結果で落ち込まず、当たった型は何度でも使い回す。

  • 伸びた投稿は使い回す … 1回当たった型は、切り口を変えて何度でも出す。
  • 1本で一喜一憂しない … 1本目が伸びなくても普通。何本も出して「再現できる型」を探す。
  • 「今さら」は捨てる … 古い型に見えても、自分のジャンルではまだ刺さることがある。

5メンバーさんへのアドバイス

ジャンルごとに「今やるとよいこと」を短くまとめました。

うささん（晩酌・おつまみレシピ）

やること：3本くらいで判断せず、まず投稿数を増やす。レシピだけでなく、自分の生活が伝わる映像を入れる。

はっちさん（産後ダイエット）

やること：ビフォーを具体的に（例：デニムの上にお腹が乗る）。「○日後こうなる」など変化のストーリーを見せる。

うぴさん（平日まるごと冷凍ストック）

やること：「自分向け」と分かるのは大事。ただし冒頭で対象を絞りすぎない（見る人を減らしすぎない）。

もあさん（アラフィフ一人旅）

やること：1本目の大ヒットを超えようと焦らない。いろんな企画を試す。プロフィールが強いので、「もっと見たい」と思わせる締めを試す。

あこさん（麹×ダイエット）

やること：コンサル前に「誰に・何を・なぜ」を整理する。伸びた投稿は同じ型で使い回す。

猫柳さん（犬アカウント）

やること：「もう遅いかも」は捨てる。やりたい企画は1回は試してから判断する。

6オフ会・個別コンサルの使い方

一言で言うと

オフ会は1枚のメモを持っていく。コンサルは無料の機会を先に使い、本当に困った時の切り札に。

オフ会：1枚に書いておくこと

  • 自己紹介（Discord名、期・チーム、ジャンル、インスタ、QRコード）
  • 聞きたいこと（自分の考えも書く）

聞き方のコツ：「どう思いますか？」より「私はこう思うのですが、合っていますか？」の方が、具体的な答えがもらいやすい。

個別コンサル：いつ使う？

  • まず質問ライブ・添削ライブなど無料の場を使い切る
  • それでも迷う時、何度相談しても伸びない時、方向を大きく変える時に使う
